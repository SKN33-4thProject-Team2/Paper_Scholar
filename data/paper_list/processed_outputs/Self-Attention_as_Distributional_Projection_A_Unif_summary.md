# Self-Attention as Distributional Projection: A Unified Interpretation of Transformer Architecture 요약본

## 1. 연구 배경 및 목적

### 1.1 연구 배경

트랜스포머의 자기어텐션은 일반적으로 다음과 같이 설명된다.

\[
\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
\]

여기서 \(Q\), \(K\), \(V\)는 입력 표현에 학습된 선형변환을 적용한 결과다. 기존 설명은 주로 “쿼리가 키를 검색하고 해당 값을 가져온다”는 정보 검색 비유에 의존해 왔다. 그러나 논문은 이러한 설명이 실제 연산의 본질을 충분히 설명하지 못한다고 지적한다. 자기어텐션에는 데이터베이스 검색이나 명시적인 조회 과정이 없으며, \(Q\), \(K\), \(V\)는 모두 학습된 선형 사상일 뿐이라는 것이다.

이에 따라 논문은 자기어텐션의 대수적 형식이 단순한 경험적 설계가 아니라, **분포 의미론(distributional semantics)**에서 출발하는 자연스러운 수학적 확장이라고 주장한다. 특히 GloVe와 같은 방법이 사용하는 전역 공기 통계(co-occurrence statistics)를 입력 시퀀스의 국소적 맥락으로 사영하는 과정에서 자기어텐션의 핵심 구조가 도출된다고 본다.

### 1.2 연구 목적

논문의 목적은 다음 네 가지로 요약된다.

1. **전역 공기 통계와 자기어텐션의 연결**  
   말뭉치 수준의 공기 행렬 \(S\)를 현재 입력 시퀀스에 제한하는 연산을 통해 자기어텐션의 기초를 설명한다.

2. **쿼리–키 분할의 원리적 정당화**  
   쿼리와 키를 서로 다른 선형변환으로 두는 이유를 방향성 있는 언어 관계에서 찾는다. 즉, 주어와 목적어, 원인과 결과처럼 본질적으로 비대칭적인 관계를 표현하기 위해 \(W_Q\)와 \(W_K\)가 분리된다고 설명한다.

3. **위치 인코딩과 다중 헤드의 통합적 해석**  
   위치 인코딩은 순열 불변적인 공기 사영에 순서 정보를 추가하는 과정으로, 다중 헤드는 서로 다른 관계 유형을 병렬적으로 사영하는 구조로 해석한다.

4. **트랜스포머 전체 구조에 대한 개념적 설명**  
   전역 통계에서 출발해 국소 맥락, 방향성, 위치, 다중 관계 표현으로 이어지는 연쇄를 제시함으로써 트랜스포머 아키텍처를 하나의 통합된 사영 체계로 설명한다.

핵심 주장은 다음과 같다.

\[
S
\rightarrow QSQ^\top
\rightarrow QW_QW_K^\top Q^\top
\rightarrow \operatorname{softmax}\left(\frac{HW_QW_K^\top H^\top}{\sqrt{d_k}}\right)(HW_V)
\]

즉, 트랜스포머 자기어텐션은 분포적 공기 구조를 시퀀스 특이적이고, 방향성이 있으며, 위치에 민감한 표현 공간으로 변환하는 학습 가능한 일반화라는 관점이다.

## 2. 핵심 방법론 및 아키텍처

### 2.1 전역 공기 행렬과 시퀀스 사영

논문은 \(n\)개 토큰 유형 사이의 전역 공기 관계를 다음 행렬로 나타낸다.

\[
S\in\mathbb{R}^{n\times n}
\]

\(S_{ij}\)는 토큰 \(i\)와 \(j\) 사이의 경험적 연관성 또는 공기 강도를 의미한다. 각 행은 특정 토큰이 어떤 단어들과 함께 나타나는지를 나타내는 분포적 의미 표현으로 간주된다.

길이 \(R\)인 입력 시퀀스에 포함된 토큰을 선택하는 행렬을 \(Q\in\mathbb{R}^{R\times n}\)라 하면, 논문은 전역 공기 구조를 시퀀스 내부 관계로 제한하는 연산을 다음과 같이 정의한다.

\[
M=QSQ^\top
\]

이때 \(M\in\mathbb{R}^{R\times R}\)의 원소는 다음과 같다.

\[
M_{rs}=q_rSq_s^\top
\]

이는 시퀀스의 \(r\)번째 토큰과 \(s\)번째 토큰이 전역 공기 구조상 얼마나 호환되는지를 나타낸다. 따라서 \(M\)은 입력 토큰들 사이의 맥락적 관계 행렬로 해석된다.

논문의 직관은 다음과 같다.

- 여러 입력 토큰이 동일한 의미적 이웃을 공유하면 해당 관계가 강화된다.
- 특정 토큰 하나에만 의존하는 연관성은 전체 맥락에서 상대적으로 약화된다.
- 따라서 다의적인 단어의 의미가 주변 토큰에 의해 선택적으로 부각될 수 있다.

예를 들어 “river bank flooded”에서는 `bank`의 금융 관련 이웃인 `loan`, `money`보다 `river`, `flooded`, `shore`와 연결되는 지리적 의미가 강화된다고 설명한다. 반대로 “bank loan”에서는 `bank`의 금융적 의미가 활성화되어 `money`와 같은 금융 관련 어휘가 높은 예측 점수를 얻는다고 제시한다.

### 2.2 정규화와 어텐션 가중치

원시 관계 행렬 \(M\)을 어텐션 가중치처럼 사용하기 위해 행 정규화를 적용한다.

\[
\operatorname{Norm}(M)_{rs}
=
\frac{M_{rs}}{\sum_t M_{rt}}
\]

이 연산은 각 토큰이 다른 토큰에 부여하는 상대적 영향력을 확률분포와 유사한 형태로 변환한다. 논문은 이를 통해 자기어텐션이 본질적으로 **맥락적 공기 관계의 정규화된 재분배**라고 해석한다.

다만 표준 트랜스포머의 정규화는 단순한 행 합 정규화가 아니라 소프트맥스다.

\[
A=\operatorname{softmax}\left(\frac{S_{\mathrm{att}}}{\sqrt{d_k}}\right)
\]

따라서 논문의 행 정규화는 실제 트랜스포머의 정확한 연산이라기보다는, 공기 행렬 기반 관계를 어텐션 분포로 변환하는 개념적 초기 모델에 해당한다.

### 2.3 어휘 수준 예측으로의 확장

시퀀스 내부 관계를 계산하는 것만으로는 다음 토큰을 예측할 수 없기 때문에, 논문은 관계 행렬 \(M\)을 전역 어휘 연관성 \(QS\)와 결합한다.

\[
E=M(QS)
=
(QSQ^\top)(QS)
\]

각 원소는 다음과 같이 해석된다.

\[
E_{rj}
=
\sum_{s=1}^{R}M_{rs}(QS)_{sj}
\]

즉, 위치 \(r\)의 토큰이 다른 입력 토큰 \(s\)에 부여한 가중치 \(M_{rs}\)를 이용해, 각 토큰이 어휘 항목 \(j\)에 대해 제공하는 증거를 결합한다.

- 여러 토큰과 일관되게 연결된 어휘 항목은 점수가 증가한다.
- 하나의 토큰에만 연결된 어휘 항목은 상대적으로 희석된다.
- 전체 시퀀스의 의미적 일관성과 부합하는 어휘 후보가 강조된다.

전체 위치의 예측 증거를 평균내면,

\[
e_{\mathrm{global}}
=
\frac{1}{R}\sum_{r=1}^{R}E_r
\]

이를 소프트맥스에 넣어 다음 토큰 분포를 얻는다.

\[
p(w_i\mid \text{context})
=
\frac{\exp(e_{\mathrm{global},i})}
{\sum_j\exp(e_{\mathrm{global},j})}
\]

이 구조는 자기어텐션이 단순히 토큰 간 유사도를 계산하는 것이 아니라, **시퀀스 전체의 분포적 증거를 결합해 어휘 수준의 예측으로 확장하는 과정**이라는 해석을 제공한다.

### 2.4 위치 정보의 도입

기본 사영 \(M=QSQ^\top\)는 토큰의 집합만 반영하고 순서를 구분하지 못한다. 즉, 동일한 토큰들이 포함되어 있다면 순서가 달라도 유사한 관계 행렬을 만들 수 있다.

이를 해결하기 위해 논문은 선택 행렬에 위치 행렬 \(P\)를 더한다.

\[
Q'=Q+P
\]

그러면 위치를 포함한 사영은 다음과 같다.

\[
M'=Q'S(Q')^\top
\]

이를 전개하면,

\[
M'
=
QSQ^\top
+
QSP^\top
+
PSQ^\top
+
PSP^\top
\]

각 항은 다음과 같이 해석된다.

- \(QSQ^\top\): 토큰 내용과 토큰 내용 사이의 관계
- \(QSP^\top\): 내용이 특정 위치와 맺는 관계
- \(PSQ^\top\): 위치가 특정 내용의 실현을 제약하는 관계
- \(PSP^\top\): 위치 간 구조 및 거리 편향

논문은 이 교차항들이 토큰 정체성과 위치를 결합함으로써 순열 불변성을 깨고, 주어–동사–목적어와 같은 순서 구조를 표현할 수 있다고 주장한다.

### 2.5 방향성 관계와 쿼리–키 구조

대칭적인 공기 행렬 \(S\)는 다음과 같은 관계를 충분히 표현하지 못한다.

- 행위자 \(\rightarrow\) 대상
- 주어 \(\rightarrow\) 동사
- 원인 \(\rightarrow\) 결과

이를 위해 논문은 서로 다른 두 선형변환 \(W_Q\), \(W_K\)를 도입한다.

\[
Q_{\mathrm{att}}=QW_Q,
\qquad
K_{\mathrm{att}}=QW_K
\]

그러면 방향성 관계 행렬은 다음과 같다.

\[
M_{\mathrm{dir}}
=
Q_{\mathrm{att}}K_{\mathrm{att}}^\top
=
QW_QW_K^\top Q^\top
\]

일반적으로

\[
W_QW_K^\top
\neq
W_KW_Q^\top
\]

이므로,

\[
(M_{\mathrm{dir}})_{rs}
\neq
(M_{\mathrm{dir}})_{sr}
\]

가 가능하다. 이로써 토큰 \(r\)이 토큰 \(s\)를 참고하는 정도와, 토큰 \(s\)가 토큰 \(r\)을 참고하는 정도를 다르게 표현할 수 있다.

논문의 핵심 해석은 쿼리와 키가 실제로 검색자와 데이터베이스 항목이라는 것이 아니라, **방향성 있는 분포 관계를 표현하기 위한 비대칭 쌍선형 사상의 두 인자**라는 것이다.

### 2.6 값 사영과 표준 자기어텐션

값 사영은 다음과 같이 정의된다.

\[
V_{\mathrm{att}}=QW_V
\]

현재 층의 표현 \(H\in\mathbb{R}^{R\times d_{\mathrm{model}}}\)를 사용하는 실제 트랜스포머 형태는 다음과 같다.

\[
Q_{\mathrm{att}}=HW_Q,\quad
K_{\mathrm{att}}=HW_K,\quad
V_{\mathrm{att}}=HW_V
\]

\[
A=
\operatorname{softmax}
\left(
\frac{Q_{\mathrm{att}}K_{\mathrm{att}}^\top}
{\sqrt{d_k}}
\right)
\]

\[
Y=AV_{\mathrm{att}}
\]

따라서 최종 표현은

\[
Y=
\operatorname{softmax}
\left(
\frac{HW_QW_K^\top H^\top}
{\sqrt{d_k}}
\right)
(HW_V)
\]

로 표현된다.

논문은 이 구조를 다음의 단계적 일반화로 본다.

1. 전역 공기 구조 \(S\)
2. 시퀀스 내부 관계 \(QSQ^\top\)
3. 방향성 관계 \(QW_QW_K^\top Q^\top\)
4. 값 공간에서의 정보 혼합 \(HW_V\)
5. 소프트맥스와 스케일링을 적용한 학습 가능한 자기어텐션

### 2.7 다중 헤드 및 교차 어텐션

다중 헤드 어텐션에서는 여러 관계 사상을 병렬로 학습한다.

\[
Q^{(i)}=HW_Q^{(i)},\quad
K^{(i)}=HW_K^{(i)},\quad
V^{(i)}=HW_V^{(i)}
\]

\[
Y^{(i)}
=
\operatorname{softmax}
\left(
\frac{Q^{(i)}K^{(i)\top}}{\sqrt{d_k}}
\right)V^{(i)}
\]

각 헤드의 결과를 연결하고 \(W_O\)로 재결합한다.

\[
Y=
[Y^{(1)}\Vert\cdots\Vert Y^{(h)}]W_O
\]

논문은 각 헤드를 서로 다른 저랭크 관계 구조의 근사로 해석한다. 예를 들어 한 헤드는 구문 관계, 다른 헤드는 공지시성, 또 다른 헤드는 주제적 응집성이나 담화 연결을 담당할 수 있다는 것이다.

교차 어텐션은 이 사영 관점을 서로 다른 두 시퀀스에 적용한 형태다.

\[
Y_{\mathrm{cross}}
=
\operatorname{softmax}
\left(
\frac{
H_{\mathrm{tgt}}W_Q
(H_{\mathrm{src}}W_K)^\top
}{\sqrt{d_k}}
\right)
(H_{\mathrm{src}}W_V)
\]

이는 타깃 시퀀스의 표현이 소스 시퀀스의 관계 구조를 비대칭적으로 참조하는 과정으로 설명된다.

## 3. 주요 실험 성과

### 3.1 실험의 성격

이 논문은 실제 트랜스포머 모델을 학습시키거나 표준 NLP 벤치마크에서 성능을 비교한 실증 연구가 아니다. 논문 스스로도 연구의 성격을 다음과 같이 규정한다.

- 학습된 모델을 사용하지 않는다.
- 외부 데이터셋이나 실험 코드가 필요하지 않다.
- 소규모로 구성한 공기 행렬을 이용해 개념적 작동을 설명한다.
- 예시는 실제 언어 모델 성능을 검증하기 위한 것이 아니라 수식의 직관을 제공하기 위한 것이다.

따라서 여기서 말하는 “실험 성과”는 엄밀한 의미의 경험적 성능 개선이라기보다, **간단한 행렬 계산을 통한 개념적 검증 및 수학적 유도 결과**로 이해해야 한다.

### 3.2 공기 사영의 개념적 검증

논문은 “river bank flooded”와 “bank loan”이라는 두 예시를 이용해 동일한 전역 공기 행렬이 입력 맥락에 따라 다른 관계와 예측을 만들어낼 수 있음을 보인다.

#### 지리적 맥락

“river bank flooded”에서는 `bank`가 금융적 의미와 지리적 의미를 모두 가질 수 있지만, 입력 시퀀스 안에서는 `river`, `flooded`, `shore`와 연결되는 지리적 의미가 강화된다.

제시된 정규화 행렬은 각 토큰이 다른 토큰에 주의를 분배하는 구조를 보여준다.

\[
\operatorname{Norm}(M)
=
\begin{bmatrix}
0.00&0.44&0.56\\
0.57&0.00&0.43\\
0.62&0.38&0.00
\end{bmatrix}
\]

이 구조를 통해 논문은 다음을 주장한다.

- `river`와 `flooded`가 `bank`의 지리적 의미를 지지한다.
- 금융 관련 이웃인 `loan`, `money`는 현재 시퀀스에서 직접적인 지지를 받지 못한다.
- 따라서 `bank`의 금융 의미는 억제되고 지리적 의미가 선택된다.

어휘 예측 단계에서는 `shore`가 높은 점수를 얻고, 최종 소프트맥스 분포에서 거의 확률 1에 가까운 다음 토큰으로 선택된다.

#### 금융적 맥락

“bank loan”에서는 `bank`와 `loan`의 직접적인 금융 공기가 강하게 작용한다. 논문은 두 토큰 사이의 관계가 사실상 전적으로 상호 연결되는 예시를 제시한다.

\[
\operatorname{Norm}(M)
=
\begin{bmatrix}
0.00&1.00\\
1.00&0.00
\end{bmatrix}
\]

이후 어휘 수준 예측에서 `money`가 가장 높은 점수를 얻고, 다음 토큰으로 거의 확률 1에 가깝게 선택된다.

이 예시는 공기 사영이 다음과 같은 방식으로 다의성을 처리한다는 논리를 보여준다.

- 맥락적으로 지지되는 의미는 여러 토큰의 증거를 통해 강화된다.
- 맥락에서 고립된 의미는 상대적으로 희석된다.
- 동일한 단어라도 주변 토큰에 따라 다른 예측이 생성된다.

### 3.3 이론적 결과

논문에서 가장 명시적인 수학적 결과는 사영의 유일성에 관한 명제다. \(T(S)\)가 선택된 토큰 집합에만 의존하고, 모든 벡터 쌍의 내적을 보존한다면,

\[
u^\top T(S)v
=
(Q^\top u)^\top S(Q^\top v)
\]

이고, 따라서

\[
T(S)=QSQ^\top
\]

라는 결론을 얻는다.

이 결과는 특정한 내적 보존 조건 아래에서 전역 관계를 선택된 시퀀스 부분공간으로 제한하는 선형 연산자가 \(QSQ^\top\)로 결정된다는 것을 보인다. 논문은 이를 자기어텐션의 초기 대수 구조에 대한 원리적 정당화로 해석한다.

### 3.4 성과의 범위와 해석

논문의 성과는 다음과 같이 평가할 수 있다.

- 자기어텐션의 \(QK^\top\) 구조를 분포 의미론의 공기 관계와 연결했다.
- 쿼리–키 분리를 방향성 비대칭의 관점에서 설명했다.
- 위치 인코딩과 다중 헤드를 동일한 사영 체계의 확장으로 묶었다.
- 교차 어텐션까지 동일한 비대칭 사영으로 해석했다.
- 표준적인 “검색” 비유를 대체할 대수적 해석을 제안했다.

그러나 이 논문이 실제로 입증한 것은 “이러한 구조로 해석할 수 있다”는 개념적·수학적 가능성이지, 이 사영 모델이 실제 트랜스포머의 학습 메커니즘이나 성능을 정확히 설명한다는 경험적 사실은 아니다.

## 4. 연구의 시사점 및 한계점

### 4.1 연구의 주요 시사점

#### 첫째, 자기어텐션을 관계 재분배 연산으로 볼 수 있다

자기어텐션은 단순히 관련 토큰을 검색하는 연산이라기보다, 각 토큰이 가진 분포적 증거를 맥락에 따라 재가중하고 서로 전달하는 연산으로 해석할 수 있다.

\[
\text{전역 분포 구조}
\rightarrow
\text{시퀀스 내부 관계}
\rightarrow
\text{맥락화된 표현}
\]

이 관점은 어텐션 가중치를 단순한 “중요도”가 아니라, 맥락적 관계의 방향과 강도를 나타내는 행렬로 이해하게 한다.

#### 둘째, 쿼리–키 분리는 임의적인 명명법이 아니라 비대칭성의 표현이다

논문은 \(W_Q\)와 \(W_K\)를 서로 다르게 두는 이유를 명확히 한다. 자연어 관계는 대칭적이지 않으므로, 하나의 대칭 유사도 함수만으로는 문법적 역할이나 방향성을 충분히 표현할 수 없다.

이 해석은 다음과 같은 현상을 이해하는 데 유용하다.

- 주어와 목적어의 역할 차이
- 행위자와 대상의 차이
- 원인과 결과의 방향성
- 한 토큰이 다른 토큰을 해석하는 방식의 비대칭성

#### 셋째, 위치 인코딩은 내용 관계에 순서 구조를 부여하는 장치다

위치 인코딩은 단순히 위치 벡터를 더하는 보조 기능이 아니라, 본래 순서에 무관한 관계 사영을 순서 민감한 사영으로 확장하는 장치로 해석된다. 이는 트랜스포머가 순환구조나 합성곱 없이도 순서 정보를 사용할 수 있는 이유를 설명하는 직관을 제공한다.

#### 넷째, 다중 헤드는 관계 구조의 분해로 이해할 수 있다

다중 헤드는 같은 관계를 여러 번 계산하는 중복 장치가 아니라, 서로 다른 유형의 관계를 병렬적으로 학습하는 구조로 볼 수 있다. 이 관점은 특정 헤드가 구문, 의미, 공지시성, 장거리 의존성 등에 특화되는 관찰과 연결된다.

#### 다섯째, 분포 의미론과 현대 신경망을 연결한다

GloVe나 전통적 행렬 기반 의미론은 전역 공기 통계에 기반하고, 트랜스포머는 이를 문맥 특이적이고 학습 가능한 방식으로 확장한다는 통합적 관점을 제시한다. 따라서 트랜스포머는 고전적 분포 의미론과 단절된 모델이라기보다, 이를 방향성·순서성·비선형성 측면에서 일반화한 체계로 이해될 수 있다.

### 4.2 이론적·기술적 한계

#### 첫째, 실제 실험적 검증이 없다

가장 큰 한계는 실제 데이터나 모델을 이용한 검증이 없다는 점이다.

- 실제 말뭉치에서 \(S\)를 구성하지 않았다.
- GloVe 행렬과 학습된 \(W_Q,W_K,W_V\) 사이의 정량적 대응을 분석하지 않았다.
- 어텐션 패턴이나 다의성 해소 성능을 실제 모델과 비교하지 않았다.
- 언어 모델링, 번역, 질의응답 등의 벤치마크 평가가 없다.

따라서 “자기어텐션이 실제로 공기 행렬 사영에서 출현한다”는 주장은 현재로서는 강한 경험적 결론이라기보다 해석적 가설에 가깝다.

#### 둘째, \(S\)와 \(W_QW_K^\top\)의 연결이 개념적이다

논문도 인정하듯이, 고정된 말뭉치 공기 행렬 \(S\)와 신경망이 학습한 \(W_QW_K^\top\)가 실제로 동일하거나 직접적으로 대응한다는 증거는 제시되지 않는다.

둘은 형식적으로 유사한 행렬 구조를 갖지만, 다음 측면에서 다르다.

- \(S\)는 관측된 전역 통계에 기반한다.
- \(W_Q,W_K\)는 과제 손실을 최소화하도록 학습된다.
- 트랜스포머의 \(H\)는 고정된 원-핫 토큰이 아니라 앞선 층의 문맥 표현이다.
- \(W_QW_K^\top\)는 층, 헤드, 입력 표현에 따라 기능적으로 달라질 수 있다.

따라서 이 논문은 직접적인 동일성보다는 구조적 유사성과 해석 가능성을 주장하는 것으로 보는 것이 타당하다.

#### 셋째, 사영이라는 용어가 엄밀한 의미에서 제한적이다

\[
QSQ^\top
\]

는 전형적인 직교 사영 행렬 \(P\)의 형태라기보다, 선택 행렬을 이용한 **부분행렬 추출 또는 관계 제한(restriction)**에 가깝다. 특히 \(Q\)가 원-핫 선택 행렬일 때 이 연산은 \(S\)에서 선택된 행과 열을 추출하는 구조다.

또한 \(Q+P\) 역시 일반적으로 직교 사영이나 선택 행렬이 아니다. 따라서 “분포적 사영”이라는 표현은 엄밀한 투영기하학적 의미보다는, 전역 관계를 국소 맥락으로 제한하고 변환한다는 넓은 의미로 이해해야 한다.

#### 넷째, 행 정규화와 소프트맥스의 차이가 크다

논문은 초기 단계에서 다음과 같은 행 정규화를 사용한다.

\[
\frac{M_{rs}}{\sum_tM_{rt}}
\]

하지만 실제 공기 행렬은 음수 값을 가질 수 있고, 행 합이 0이거나 음수가 될 수도 있다. 이 경우 해당 값은 확률분포로 직접 해석하기 어렵다. 반면 트랜스포머는 소프트맥스를 사용하여 모든 점수를 양의 확률로 변환한다.

따라서 논문의 정규화는 실제 어텐션의 정확한 수학적 모델이라기보다 직관적 근사다. 공기 통계의 종류, 로그 변환, PMI 사용 여부, 음수 값 처리 등에 대한 논의가 추가로 필요하다.

#### 다섯째, 위치 인코딩의 수식적 구성에 엄밀성이 부족하다

논문은 \(Q'=Q+P\)를 사용하지만, \(Q\)는 \(R\times n\) 크기의 선택 행렬이고 \(P\)도 같은 공간에 있어야 한다. 실제 트랜스포머의 위치 인코딩은 보통 \(d_{\mathrm{model}}\)-차원 임베딩 공간에서 토큰 표현에 더해진다.

따라서 다음 두 수준이 구분되어야 한다.

- 어휘 원-핫 공간에서의 위치 행렬 \(P\)
- 임베딩 표현 공간에서의 위치 벡터 또는 위치 변환

논문은 이 둘을 개념적으로 연결하지만, 실제 구현 수준에서 어떻게 동일한 사영 형식으로 정합되는지는 충분히 제시하지 않는다.

#### 여섯째, 사영의 유일성 명제는 조건에 크게 의존한다

명제의 증명은 조건 (ii)에 이미 사실상 목표식이 포함되어 있기 때문에 비교적 자명하다. 내적 보존 조건을

\[
u^\top T(S)v
=
(Q^\top u)^\top S(Q^\top v)
\]

로 정의하면, 우변을 전개해 \(T(S)=QSQ^\top\)를 얻는 것은 자연스럽다. 그러나 이 결과는 자기어텐션의 필요충분조건을 보여준다기보다, 특정한 내적 보존 정의 아래에서 해당 연산자가 유일함을 보이는 결과다.

즉 다음과 같은 더 강한 주장은 아직 입증되지 않았다.

- \(QSQ^\top\)가 언어 모델링에 최적이라는 것
- 다른 비선형 또는 비선형 사영보다 우월하다는 것
- 실제 트랜스포머의 어텐션 행렬이 이 구조를 근사한다는 것

#### 일곱째, 현대 트랜스포머의 전체 구성요소를 모두 설명하지는 못한다

논문은 자기어텐션을 중심으로 분석하지만, 실제 트랜스포머의 성능은 다음 요소들과도 밀접하게 관련된다.

- 피드포워드 네트워크
- 잔차 연결
- 층 정규화
- 학습 목적함수
- 토큰화
- causal mask
- 출력 언어모델 헤드
- 깊은 층을 통한 반복적 표현 갱신

이러한 요소들은 본 사영 체계에서 충분히 다뤄지지 않는다. 특히 자기어텐션만으로 트랜스포머 전체의 표현 능력과 학습 동역학을 설명하기에는 범위가 제한적이다.

### 4.3 종합 평가

이 논문은 트랜스포머를 새롭게 학습시키는 알고리즘을 제안한 연구라기보다, 이미 널리 사용되는 자기어텐션의 대수적 구조를 분포 의미론의 관점에서 재해석한 이론적·개념적 연구다.

가장 중요한 기여는 다음의 연결고리를 제시한 데 있다.

\[
\text{공기 통계}
\rightarrow
\text{시퀀스 관계 사영}
\rightarrow
\text{방향성 관계}
\rightarrow
\text{위치 민감성}
\rightarrow
\text{다중 관계 표현}
\rightarrow
\text{트랜스포머 어텐션}
\]

이 관점은 쿼리–키–값, 위치 인코딩, 다중 헤드를 서로 별개의 경험적 장치가 아니라, 전역 분포 구조를 맥락적·방향적·순서적 표현으로 확장하는 과정으로 이해하게 한다.

다만 현재의 결과는 주로 수학적 유사성과 설명 가능성에 기반한다. 향후에는 실제 말뭉치의 공기 행렬과 사전학습 트랜스포머의 \(QK^\top\)를 비교하고, 공기 통계로 초기화한 모델과 표준 모델의 성능·학습 안정성·어텐션 패턴을 평가해야 이론의 실증적 타당성을 검증할 수 있다.
