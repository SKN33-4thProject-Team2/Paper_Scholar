# 「Improving Sample Quality of Diffusion Models Using Self-Attention Guidance」 심층 요약

## 1. 연구 배경 및 목적

### 1.1 연구 배경

확산 모델은 단계적으로 잡음을 제거하는 역과정을 통해 이미지를 생성하며, 높은 품질과 다양성을 동시에 달성해 왔다. 특히 다음과 같은 가이던스 기법이 성능 향상에 핵심적인 역할을 했다.

- **분류기 가이던스(Classifier Guidance, CG)**  
  별도로 학습된 분류기의 그래디언트를 활용해 샘플을 특정 클래스 방향으로 유도한다.
- **분류기 없는 가이던스(Classifier-Free Guidance, CFG)**  
  조건부 모델과 비조건부 모델의 예측 차이를 이용해 조건을 강화하며, 별도 분류기는 필요하지 않지만 학습 시 조건 제거 전략이 필요하다.
- **텍스트 또는 CLIP 기반 가이던스**  
  텍스트 프롬프트나 외부 의미 정보를 이용해 생성 결과를 원하는 방향으로 유도한다.

이러한 방법들은 높은 충실도(fidelity)를 제공하지만 공통적으로 다음과 같은 제약을 가진다.

1. 클래스 레이블, 텍스트 프롬프트와 같은 **외부 조건**이 필요하다.
2. 분류기 학습이나 조건 제거 학습 등 **추가 학습 절차**가 필요할 수 있다.
3. 레이블이나 텍스트 조건이 없는 비조건부 모델에는 직접 적용하기 어렵다.
4. 조건 정보가 충분하지 않거나 부정확하면 생성 결과가 조건에 과도하게 종속될 수 있다.

### 1.2 연구 목적

본 연구의 핵심 목적은 확산 모델이 생성 과정 중 내부적으로 형성하는 정보를 이용하여, 외부 조건이나 추가 학습 없이 샘플 품질을 개선하는 것이다.

이를 위해 저자들은 확산 모델 내부의 **자기 어텐션 맵(self-attention map)**을 활용하는 **자기 어텐션 가이던스(Self-Attention Guidance, SAG)**를 제안한다. SAG는 모델이 중요하다고 판단한 이미지 영역을 선택적으로 손상시킨 뒤, 원본 입력과 손상된 입력에 대한 모델 예측 차이를 이용해 역확산 과정을 조정한다.

연구가 제시하는 기본 관점은 다음과 같다.

> 확산 모델의 중간 샘플 안에 이미 포함된 내부 정보를 추출하고, 해당 정보가 제거된 입력에 대한 모델 예측을 비교하면 외부 조건 없이도 가이던스를 구성할 수 있다.

즉, 기존 가이던스가 “외부 조건을 더 잘 만족하도록” 모델을 유도했다면, SAG는 “현재 샘플에 포함된 중요한 내부 구조와 세부 정보를 더 잘 보존하도록” 모델을 유도한다.

## 2. 핵심 방법론 및 아키텍처

## 2.1 확산 모델의 역과정과 중간 복원

확산 모델은 시점 \(t\)의 noisy sample \(\mathbf{x}_t\)에서 잡음을 예측하고, 이를 이용해 이전 시점 \(\mathbf{x}_{t-1}\)을 계산한다.

\[
\mathbf{x}_{t-1}
=
\frac{1}{\sqrt{\bar{\alpha}_t}}
\left(
\mathbf{x}_t
-
\frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}}
\epsilon_\theta(\mathbf{x}_t,t)
\right)
+
\sigma_t\mathbf{z}.
\]

이때 모델의 잡음 예측값으로부터 현재 시점에서 원본 이미지에 해당하는 중간 복원값 \(\hat{\mathbf{x}}_0\)을 추정할 수 있다.

\[
\hat{\mathbf{x}}_0
=
\frac{
\mathbf{x}_t-\sqrt{1-\bar{\alpha}_t}\epsilon_\theta(\mathbf{x}_t,t)
}{
\sqrt{\bar{\alpha}_t}
}.
\]

SAG는 바로 이 중간 복원값을 활용하여 이미지의 일부 세부 정보를 의도적으로 제거하고, 그 결과를 다시 현재 잡음 수준으로 되돌린다.

---

## 2.2 확산 가이던스의 일반화

저자들은 CG와 CFG를 포괄할 수 있는 일반화된 가이던스 관점을 제안한다. 시점 \(t\)에서 모델 입력을 다음 두 부분으로 나눈다.

- \(\bar{\mathbf{x}}_t\): 일부 정보가 제거된 입력
- \(h_t\): 제거된 정보 또는 외부 조건

이때 \(\bar{\mathbf{x}}_t\)만 이용해 예측한 결과와, 제거된 정보 \(h_t\)까지 포함한 원래 입력에 대한 결과의 차이를 활용하여 가이던스를 구성한다.

일반적인 형태는 다음과 같이 표현된다.

\[
\tilde{\epsilon}(\bar{\mathbf{x}}_t,h_t)
=
\epsilon_\theta(\bar{\mathbf{x}}_t,h_t)
+
s\left(
\epsilon_\theta(\bar{\mathbf{x}}_t,h_t)
-
\epsilon_\theta(\bar{\mathbf{x}}_t)
\right).
\]

또는 동치 형태로,

\[
\tilde{\epsilon}
=
\epsilon_\theta(\bar{\mathbf{x}}_t)
+
(1+s)
\left(
\epsilon_\theta(\bar{\mathbf{x}}_t,h_t)
-
\epsilon_\theta(\bar{\mathbf{x}}_t)
\right).
\]

이는 CFG의 구조와 유사하지만, 여기서 \(h_t\)는 반드시 클래스나 텍스트일 필요가 없다. 이미지 내부에서 추출한 정보도 \(h_t\)로 사용할 수 있다.

---

## 2.3 블러 가이던스

SAG에 앞서 저자들은 보다 단순한 형태의 **블러 가이던스(blur guidance)**를 제안한다.

### 처리 과정

1. 현재 noisy sample \(\mathbf{x}_t\)에서 \(\hat{\mathbf{x}}_0\)을 복원한다.
2. \(\hat{\mathbf{x}}_0\)에 Gaussian blur를 적용해 \(\tilde{\mathbf{x}}_0\)을 얻는다.
3. 블러 처리된 이미지에 다시 동일한 수준의 잡음을 추가해 \(\tilde{\mathbf{x}}_t\)를 만든다.
4. \(\mathbf{x}_t\)와 \(\tilde{\mathbf{x}}_t\)의 차이를 제거된 세부 정보로 간주한다.
5. 원본 입력과 블러 입력에 대한 모델의 잡음 예측 차이를 가이던스에 사용한다.

블러는 주로 고주파 세부 정보를 제거하므로, 모델이 이미지의 세밀한 구조를 복원하도록 유도할 수 있다.

그러나 전체 이미지에 전역적으로 블러를 적용하면 큰 가이던스 강도에서 문제가 발생한다. 이미지 전체의 구조가 흐려져 원본 입력과 열화된 입력 사이의 예측 차이가 지나치게 커지고, 반복적인 역과정에서 오차가 누적되어 노이즈와 구조적 불안정성이 나타난다.

---

## 2.4 자기 어텐션 가이던스(SAG)

SAG는 전역 블러의 불안정성을 줄이기 위해 **자기 어텐션이 높은 영역만 선택적으로 블러 처리**한다.

### 핵심 직관

확산 모델의 자기 어텐션은 이미지 생성에 중요한 영역과 세부 정보를 포착한다. 실험적으로 자기 어텐션이 높은 영역은 다음 특성을 보였다.

- 고주파 세부 정보가 많다.
- 전경 객체나 의미 있는 구조와 일정 부분 겹친다.
- 여러 객체 또는 모델이 정교하게 표현해야 하는 영역에 집중된다.

따라서 모델이 중요하다고 판단하는 영역을 선택적으로 가리고, 해당 영역에 담긴 정보를 이용하여 모델을 가이던스하면 전역적인 구조 손상 없이 세부 정보 개선을 유도할 수 있다.

### 구체적 처리 과정

1. 확산 모델에 \(\mathbf{x}_t\)를 입력한다.
2. 모델의 중간 자기 어텐션 맵들을 평균 및 업샘플링하여 이미지 해상도에 맞는 집계 어텐션 맵 \(A_t\)를 만든다.

\[
A_t
=
\operatorname{Upsample}
\left(
\operatorname{Reshape}
\left(
\operatorname{GAP}(A_t^S)
\right)
\right).
\]

3. 어텐션 맵의 임계값 \(\psi\)를 기준으로 마스크를 생성한다.

\[
M_t=\mathbf{1}(A_t>\psi).
\]

실험에서는 주로 어텐션 맵의 평균값 또는 이에 대응하는 임계값을 사용했다.

4. \(\hat{\mathbf{x}}_0\)을 복원하고 Gaussian blur를 적용한다.
5. 블러 처리된 결과를 다시 현재 시점의 잡음 수준으로 확산시켜 \(\tilde{\mathbf{x}}_t\)를 생성한다.
6. 어텐션이 높은 영역만 블러 결과로 대체한다.

\[
\hat{\mathbf{x}}_t
=
(1-M_t)\odot\mathbf{x}_t
+
M_t\odot\tilde{\mathbf{x}}_t.
\]

즉, 어텐션이 낮은 영역은 원본 입력을 그대로 유지하고, 어텐션이 높은 영역만 손상시킨다.

7. 원본 입력 \(\mathbf{x}_t\)와 선택적으로 손상된 입력 \(\hat{\mathbf{x}}_t\)에 대해 각각 모델 예측을 수행한다.
8. 두 예측의 차이를 가이던스 방향으로 사용한다.

\[
\tilde{\epsilon}(\mathbf{x}_t)
=
\epsilon_\theta(\hat{\mathbf{x}}_t)
+
(1+s)
\left(
\epsilon_\theta(\mathbf{x}_t)
-
\epsilon_\theta(\hat{\mathbf{x}}_t)
\right).
\]

이를 이용하여 다음 역확산 단계 \(\mathbf{x}_{t-1}\)을 계산한다.

### 아키텍처적 특징

SAG는 새로운 네트워크나 학습 모듈을 추가하지 않는다.

- 기존 확산 모델의 자기 어텐션 맵을 그대로 사용한다.
- 사전 학습된 ADM, IDDPM, Stable Diffusion, DiT 등에 적용 가능하다.
- 외부 클래스나 텍스트 조건 없이도 작동한다.
- CFG나 CG와 결합할 수 있다.
- 다만 각 시점마다 추가적인 모델 순전파가 필요하다.

## 3. 주요 실험 성과

## 3.1 비조건부 확산 모델에서의 성능 향상

### ADM: ImageNet 256×256

비조건부 ADM에 SAG를 적용한 결과는 다음과 같다.

| 지표 | SAG 미적용 | SAG 적용 | 변화 |
|---|---:|---:|---:|
| FID | 26.21 | **20.08** | 크게 개선 |
| sFID | 6.35 | **5.77** | 개선 |
| IS | 39.70 | **45.56** | 개선 |
| 정밀도 | 0.61 | **0.68** | 개선 |
| 재현율 | 0.63 | 0.59 | 소폭 감소 |

FID가 26.21에서 20.08로 감소하여 생성 분포와 실제 데이터 분포의 정합성이 크게 개선되었다. IS와 정밀도도 상승했으므로 생성 샘플의 시각적 품질과 충실도가 높아졌다고 볼 수 있다.

반면 재현율은 0.63에서 0.59로 낮아졌다. 이는 SAG가 생성 결과를 더 선명하고 안정적인 방향으로 유도하는 과정에서, 전체 데이터 분포의 다양성이나 희귀한 샘플의 포괄 범위가 일부 줄어드는 **충실도-다양성 절충**을 보여준다.

### ADM: 조건부 ImageNet 256×256

조건부 모델에서도 SAG는 추가 개선을 보였다.

| 지표 | SAG 미적용 | SAG 적용 |
|---|---:|---:|
| FID | 10.94 | **9.41** |
| sFID | 6.02 | **5.28** |
| IS | 100.98 | **104.79** |
| 정밀도 | 0.69 | **0.70** |
| 재현율 | 0.63 | 0.62 |

이는 SAG가 외부 조건을 대체하는 방법일 뿐 아니라, 이미 클래스 조건을 사용하는 모델에서도 추가적인 내부 가이던스로 기능할 수 있음을 보여준다.

### LSUN Cat 및 Horse

비조건부 LSUN 모델에서는 개선 폭이 ImageNet보다 작았지만, FID와 sFID가 일관되게 개선되었다.

- LSUN Cat: FID 7.03 → **6.87**
- LSUN Horse: FID 3.45 → **3.43**

데이터셋별로 개선 정도가 다른 것은 모델의 어텐션 구조, 데이터 분포의 단순성, 기본 샘플 품질 등에 따라 SAG의 효과가 달라질 수 있음을 시사한다.

### IDDPM: ImageNet 64×64

IDDPM에서도 비조건부 모델의 FID가 다음과 같이 개선되었다.

- FID 19.2 → **18.0**

따라서 SAG의 효과가 특정 ADM 구현에만 국한되지 않고, 다른 확산 모델 계열에서도 나타남을 확인했다.

## 3.2 Stable Diffusion에서의 정성적 및 인간 평가 결과

Stable Diffusion v1.4에 SAG를 적용하고 빈 프롬프트를 사용한 실험에서, 동일한 랜덤 시드를 사용한 이미지 쌍을 비교했다.

인간 평가에서는 참가자들이 SAG가 적용된 샘플을 다음 측면에서 더 선호하는 경향을 보였다.

- 더 선명한 시각적 세부 정보
- 더 자연스러운 구조
- 감소된 아티팩트
- 전반적으로 더 높은 현실감

특히 빈 프롬프트에서도 품질 향상이 관찰되었다는 점이 중요하다. 이는 SAG가 텍스트 조건 자체를 강화한 결과가 아니라, 모델 내부 표현과 자기 어텐션을 활용해 생성 과정을 개선한 결과라는 점을 뒷받침한다.

## 3.3 기존 가이던스와의 결합

### CG와의 결합

ImageNet 128×128 ADM 실험에서 다음 결과를 얻었다.

| CG | SAG | FID | sFID | 정밀도 | 재현율 |
|---|---|---:|---:|---:|---:|
| 미적용 | 미적용 | 5.91 | 5.09 | 0.70 | 0.65 |
| 적용 | 미적용 | 2.97 | 5.09 | 0.78 | 0.59 |
| 미적용 | 적용 | 5.11 | **4.09** | 0.72 | 0.65 |
| 적용 | 적용 | **2.58** | 4.35 | **0.79** | 0.59 |

CG와 SAG를 함께 사용하면 FID가 2.97에서 2.58로, 정밀도가 0.78에서 0.79로 추가 개선되었다. 이는 두 방법이 서로 다른 정보를 이용한다는 것을 의미한다.

- CG: 외부 클래스 조건을 활용
- SAG: 이미지 내부 자기 어텐션과 세부 정보를 활용

다만 sFID는 SAG만 적용했을 때 4.09로 가장 낮았다. 따라서 SAG가 모든 평가지표를 동시에 최적화하는 것은 아니며, 가이던스 강도와 목표 지표에 따라 최적 조합이 달라질 수 있다.

### CFG와의 결합

DiT-XL/2의 ImageNet 256×256 실험에서:

- CFG만 적용: FID **2.27**
- CFG + SAG: FID **2.16**

SAG를 CFG 위에 추가하면 텍스트 조건을 유지하면서도 내부 구조와 세부 정보를 더 안정적으로 복원할 수 있었다. 이는 SAG가 CFG와 직교적인 보완 효과를 가진다는 주장을 지지한다.

| 기준선 | 5.98 | 141.72 |
| 전역 블러 | 5.82 | 143.15 |
| 고주파 마스크 | 5.74 | 148.87 |
| 무작위 마스크 | 5.68 | 148.99 |
| 정사각형 마스크 | 5.68 | 146.50 |
| DINO 어텐션 | 5.63 | 146.18 |
| **자기 어텐션(SAG)** | **5.47** | **151.12** |

SAG가 모든 비교 방법보다 우수했다. 특히 무작위 마스크나 고주파 마스크보다도 확산 모델 자체의 자기 어텐션을 사용하는 것이 효과적이었다. 이는 “어떤 영역을 손상시킬 것인가”가 성능을 좌우하는 핵심 설계 요소임을 보여준다.

### 가이던스 강도

ADM 실험에서 가이던스 강도 \(s\)를 변화시킨 결과:

- 적당한 강도인 \(s=0.1\)에서 FID, sFID, IS가 가장 좋았다.
- 정밀도는 \(s=0.3\)에서 가장 높았다.
- 음의 강도 또는 지나치게 큰 강도는 성능을 저하시켰다.

이는 SAG가 무조건 강하게 적용될수록 좋은 방법이 아니라, 모델과 해상도에 맞는 적절한 강도 조정이 필요함을 의미한다.

### 블러 강도

Gaussian blur의 표준편차 \(\sigma\)에 대한 실험에서는:

- \(\sigma \to 0\): 사실상 블러가 없어 기준선과 유사
- 중간 정도의 \(\sigma\): 가장 좋은 성능
- 지나치게 큰 \(\sigma\): 정보 손실이 커져 성능 저하

ImageNet 128×128 ADM의 예에서는 \(\sigma=3\)일 때 가장 좋은 결과를 얻었다.

- FID: 5.98 → **5.47**
- IS: 141.72 → **151.12**

최적 \(\sigma\)는 이미지 해상도와 모델 구조에 따라 달라지며, 일반적으로 해상도가 높을수록 더 큰 블러 강도가 필요할 수 있다.

## 3.5 계산 비용

계산 비용 실험은 다음과 같다.

| 방법 | GPU 메모리 | 실행 시간 |
|---|---:|---:|
| 가이던스 없음 | 12,167MB | 108.27초 |
| SAG | 12,209MB | 186.60초 |
| CFG | 12,218MB | 190.27초 |

SAG는 추가 메모리 사용량은 매우 작지만, 손상된 입력에 대한 추가 순전파가 필요하기 때문에 실행 시간이 증가한다. 계산 시간은 CFG와 비슷한 수준이다.

즉, SAG는 모델 재학습이나 추가 네트워크가 필요 없다는 점에서는 효율적이지만, 샘플링 단계의 순전파 횟수가 증가한다는 비용을 가진다.

## 4. 연구의 시사점 및 한계점

## 4.1 연구의 시사점

### 4.1.1 외부 조건 없는 확산 가이던스의 가능성 제시

기존의 확산 가이던스는 클래스, 캡션, 분류기 등 외부 정보에 의존했다. SAG는 모델의 중간 샘플과 자기 어텐션이라는 내부 정보만으로 가이던스를 수행한다.

따라서 다음과 같은 상황에 특히 유용할 수 있다.

- 레이블이 없는 데이터셋
- 텍스트 조건을 제공하기 어려운 생성 작업
- 이미 학습된 비조건부 확산 모델의 품질 개선
- 추가 모델 학습이 제한된 환경
- 기존 조건부 가이던스를 보완하는 샘플링 방법

### 4.1.2 자기 어텐션이 단순한 표현 모듈을 넘어 제어 신호가 될 수 있음을 보임

자기 어텐션은 일반적으로 모델 내부의 표현 학습이나 전역 문맥 통합을 위한 구성 요소로 이해된다. 본 연구는 자기 어텐션 맵을 직접 샘플링 제어 신호로 활용할 수 있음을 보여준다.

특히 어텐션이 높은 위치가 고주파 세부 정보와 의미적 전경 영역을 함께 포함한다는 분석은, 확산 모델의 내부 표현이 생성 과정 제어에 활용될 가능성을 제시한다.

### 4.1.3 기존 가이던스와의 직교성

SAG는 CG나 CFG를 대체하는 방법이라기보다 보완하는 방법이다.

- 외부 조건을 강화하는 CG/CFG
- 내부 세부 정보와 구조를 강화하는 SAG

서로 다른 종류의 정보를 사용하므로 결합 시 추가적인 성능 개선이 가능하다. 이는 향후 가이던스를 하나의 조건 신호가 아닌 여러 내부·외부 신호의 조합으로 설계할 수 있음을 시사한다.

### 4.1.4 모델 범용성

SAG는 특정한 하나의 확산 구조에만 의존하지 않고 다음 모델들에 적용되었다.

- ADM
- IDDPM
- Stable Diffusion
- DiT

이는 U-Net 기반 모델뿐 아니라 Transformer 기반 확산 모델에도 적용 가능함을 보여준다. 다만 각 모델에서 적절한 어텐션 계층, 블러 강도, 가이던스 강도를 조정해야 한다.

---

## 4.2 한계점

### 4.2.1 샘플 다양성 감소 가능성

SAG는 샘플을 더 안정적이고 선명한 방향으로 유도한다. 그러나 정밀도와 FID가 향상되는 동시에 재현율이 감소한 실험 결과는, 일부 다양성이나 참신성이 희생될 수 있음을 보여준다.

따라서 SAG는 다음과 같은 위험을 가질 수 있다.

- 생성 결과가 평균적이고 전형적인 형태로 수렴
- 희귀하거나 비정형적인 샘플 생성 감소
- 데이터 분포의 넓은 범위보다 높은 충실도에 편향
- 강한 가이던스에서 모드 커버리지 축소

응용 목적에 따라 가이던스 강도를 조절해야 하며, 단순히 FID만으로 품질을 판단해서는 안 된다.

### 4.2.2 추가 순전파에 따른 샘플링 속도 저하

SAG는 매 시간 단계마다 원본 입력과 손상된 입력에 대해 모델 예측을 수행한다. 따라서 가이던스가 없는 샘플링보다 실행 시간이 크게 증가한다.

또한 SAG와 CFG를 함께 사용하면 조건부·비조건부 입력 각각에 대해 추가 처리가 필요할 수 있어 계산 비용이 더 복잡해진다. 저자들은 향후 다음과 같은 방법을 해결책으로 제시한다.

- SAG 가이던스의 증류
- 가이던스 효과를 단일 모델에 통합
- 순전파 횟수 감소
- 어텐션 및 선택적 블러 계산의 효율화

### 4.2.3 하이퍼파라미터 민감성

SAG의 성능은 다음 요소에 영향을 받는다.

- 가이던스 강도 \(s\)
- 어텐션 임계값 \(\psi\)
- Gaussian blur의 \(\sigma\)
- 어텐션 맵을 추출하는 계층
- 모델의 해상도와 구조
- 적용하는 확산 시간 단계

실험에서는 특정 모델과 데이터셋에 대해 별도의 하이퍼파라미터가 사용되었다. 예를 들어 ADM, Stable Diffusion, DiT마다 적절한 강도와 계층이 달랐다. 따라서 모든 모델에 자동으로 적용할 수 있는 보편적인 설정 규칙은 아직 확립되지 않았다.

### 4.2.4 자기 어텐션의 해석 가능성 및 안정성

SAG는 자기 어텐션이 중요한 영역을 잘 포착한다는 가정에 기반한다. 그러나 자기 어텐션 맵이 항상 의미적으로 정확하거나 안정적인 것은 아니다.

- 시간 단계에 따라 어텐션의 의미가 변할 수 있다.
- 서로 다른 헤드와 계층의 어텐션이 상충할 수 있다.
- 어텐션이 실제로 중요한 생성 정보와 항상 일치한다고 보장할 수 없다.
- 모델에 따라 자기 어텐션이 충분히 존재하지 않거나 구조가 다를 수 있다.

저자들의 분석에서 확산 모델의 어텐션이 무작위 마스크나 DINO 어텐션보다 효과적이었지만, 이는 특정 모델·데이터셋에 대한 경험적 결과이며 모든 생성 모델에 일반화된 이론적 보장은 아니다.

### 4.2.5 평가 범위의 제한

실험은 ADM, IDDPM, Stable Diffusion, DiT와 ImageNet 및 LSUN 등을 중심으로 수행되었다. FID, sFID, IS, 정밀도·재현율, 인간 평가를 사용해 다각도로 검증했지만, 다음과 같은 추가 검증이 필요하다.

- 더 다양한 데이터셋과 도메인
- 대규모 고해상도 생성
- 최신 확산 모델과 샘플러
- 텍스트 조건이 복잡한 생성 작업
- 생성 다양성과 창의성에 대한 정교한 평가
- 실제 사용자 응용에서의 효용성

## 종합 평가

이 논문은 확산 모델의 샘플 품질을 개선하기 위해 외부 조건이나 추가 학습 없이 모델 내부의 자기 어텐션을 활용하는 새로운 샘플링 가이던스 방법을 제안한다. 핵심은 모델이 중요하다고 판단한 영역만 선택적으로 블러 처리하고, 원본 입력과 손상 입력 사이의 예측 차이를 이용해 역확산을 조정하는 것이다.

SAG는 비조건부 모델뿐 아니라 조건부 모델에서도 효과적이며, CG와 CFG와 결합할 때 추가적인 성능 향상을 보였다. 특히 FID, IS, 정밀도와 같은 품질·충실도 지표에서 일관된 개선을 확인했고, 인간 평가에서도 더 선명하고 자연스러운 샘플이 선호되었다.

다만 품질 향상 과정에서 다양성이 줄어들 수 있고, 추가 순전파로 인해 샘플링 시간이 증가하며, 모델별 하이퍼파라미터 조정이 필요하다. 그럼에도 본 연구는 확산 모델 가이던스의 범위를 외부 조건 중심에서 내부 표현 기반으로 확장했다는 점에서 의미가 크며, 향후 자기 조건화, 가이던스 증류, 내부 어텐션 기반 샘플 제어 연구의 중요한 출발점으로 평가할 수 있다.
