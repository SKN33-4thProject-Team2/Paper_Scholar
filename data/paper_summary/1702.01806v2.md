# Abstract

### Summary

This study focuses on improving the efficiency of Neural Machine Translation (NMT) through beam search strategies. The original approach uses a simple left-to-right beam-search decoder that generates translations word-by-word, keeping a fixed number of candidates at each time step. This paper introduces several pruning techniques to enhance this process without compromising translation quality.

The key findings are as follows:

1. **Introduction**: NMT models use a beam search strategy for generating new translations, which can be computationally expensive and may not fully explore candidate hypotheses due to the fixed beam size. The study aims to improve efficiency by reducing the number of candidates while maintaining performance.

2. **Related Work**: Previous work on pruning techniques has been applied in statistical machine translation (SMT) for tasks like phrase table pruning. This paper explores different absolute and relative pruning schemes specifically for NMT.

3. **Original Beam Search**: The original approach maintains a fixed beam size at each time step, limiting the number of candidate hypotheses to improve efficiency but potentially missing high-scoring alternatives.

4. **Search Strategies**: Various extensions are introduced:
   - Reducing the candidate list to the current beam size.
   - Discarding candidates if they have scores below a certain threshold relative to the best score.
   - Limiting the maximum number of candidates per node based on their history.

5. **Experiments**:
   - The experiments were conducted using different pruning techniques (rp, ap, rpl) and varying beam sizes (5 and 14).
   - Results show significant improvements in speed without sacrificing translation quality.
   - For example, the rp=0.6, ap=2.5, rpl=0.02, mc=3 combination achieved a 43% reduction in fan-out size compared to no pruning.

### Conclusion

The study demonstrates that by applying various pruning techniques, NMT can be significantly sped up without compromising translation quality. The results indicate that these methods are effective for improving the efficiency of beam search-based NMT systems.
