# Toward Interpretable Music Tagging with Self-Attention 요약본

# 1. 연구 배경 및 목적

## 1.1 연구 배경

자동 음악 태깅은 오디오의 내용에 따라 장르, 분위기, 악기, 보컬 유무 등 여러 태그를 동시에 예측하는 **다중 레이블 분류 문제**이다. 이러한 태그는 음악 검색, 추천, 분류 및 아카이빙에 활용된다.

기존의 음악 태깅 모델은 주로 다음과 같은 구조를 사용했다.

- **CNN 기반 모델**: 스펙트로그램의 국소적인 시간-주파수 패턴을 잘 포착하지만, 장기적인 음악 구조를 직접 모델링하기 어렵다.
- **CRNN**: CNN으로 음색·피치·화음과 같은 국소 특징을 추출하고 RNN으로 시간적 구조를 모델링한다.
- **CNN 백엔드 모델**: 여러 합성곱 층과 풀링을 통해 시간적 구조를 포착하지만, 풀링 과정에서 시간 해상도가 저하될 수 있다.
- **RNN 백엔드 모델**: 긴 시퀀스에서 계산량이 증가하고 기울기 소실·폭주 문제가 발생할 수 있다.

특히 음악의 의미는 특정 순간의 정보만으로 결정되지 않는다. 예를 들어 악기 태그는 특정 음색뿐 아니라 곡 전반에 걸친 반복적인 패턴이나 다른 악기와의 관계를 통해 판단될 수 있다. 즉, 음악은 **서로 멀리 떨어진 시간 구간 간의 장기적·희소한 관계**를 바탕으로 고차원적인 의미를 형성한다.

## 1.2 연구 목적

본 논문은 이러한 문제를 해결하기 위해 **CNN 프런트엔드와 자기 어텐션 기반 트랜스포머 인코더 백엔드**를 결합한 음악 태깅 모델을 제안한다.

연구의 핵심 목적은 다음과 같다.

1. 자기 어텐션을 이용해 기존 CNN·RNN보다 효과적으로 음악의 장기 시간 문맥을 모델링한다.
2. 음악을 단순한 시간-주파수 이미지가 아니라 **오디오 이벤트의 시간적 시퀀스**로 해석한다.
3. 모델이 어떤 시간 구간에 주의를 기울였는지, 그리고 특정 태그 예측에 어떤 구간이 기여했는지를 시각화하여 **해석 가능성**을 높인다.
4. MagnaTagATune과 Million Song Dataset에서 기존 모델과 비교해 성능 경쟁력을 검증한다.

# 2. 핵심 방법론 및 아키텍처

## 2.1 전체 구조

제안 모델은 다음의 두 단계로 구성된다.

> **입력 오디오 → CNN 프런트엔드 → 시간별 특징 시퀀스 → 자기 어텐션 백엔드 → 태그 예측**

프런트엔드는 오디오에서 음색, 피치, 화음과 같은 국소적인 정보를 추출하고, 백엔드는 이러한 국소 구성 요소들 사이의 장기적 관계를 학습한다.

논문에서는 두 종류의 프런트엔드와 세 종류의 백엔드를 조합해 실험했다.

### 프런트엔드

- **Spec**: 로그 멜 스펙트로그램을 입력으로 하는 2D CNN
- **Raw**: 원시 오디오 파형을 입력으로 하는 1D 샘플 수준 CNN

### 백엔드

- **\(CNN_P\)**: Spec 프런트엔드와 함께 사용하는 기존 CNN 백엔드
- **\(CNN_L\)**: Raw 프런트엔드와 함께 사용하는 기존 CNN 백엔드
- **Att**: 본 논문이 제안한 자기 어텐션 기반 백엔드

따라서 주요 제안 모델은 다음과 같다.

- **Spec Att**: 스펙트로그램 CNN + 자기 어텐션
- **Raw Att**: 원시 파형 CNN + 자기 어텐션

## 2.2 Spec 프런트엔드

Spec 프런트엔드는 음악 태깅에 유용한 음색 및 시간 특성을 분리해 추출하도록 설계되었다.

### 처리 과정

1. 로그 멜 스펙트로그램 입력
2. **수직 합성곱 필터**
   - 주파수 축을 따라 적용
   - 음색 관련 정보 포착
3. 주파수 축 기준 최대 풀링
4. **수평 합성곱 필터**
   - 시간적 변화와 패턴 포착
5. 주파수 축 기준 평균 풀링
6. 수직 필터와 수평 필터의 특징 결합

입력은 약 **4.1초 길이, 256 프레임**으로 구성된다. 수직 필터는 주파수 위치에 상대적으로 불변적인 음색 표현을 만들고, 수평 필터는 서로 다른 주파수 영역에서 나타나는 시간적 플럭스나 변화 패턴을 포착한다.

## 2.3 Raw 프런트엔드

Raw 프런트엔드는 STFT나 멜 스펙트로그램 변환 없이 원시 오디오 파형을 직접 입력으로 사용한다.

- 입력 길이: **65,610개 샘플**
- 샘플링 주파수: 16 kHz
- 오디오 길이: 약 4.1초
- 짧은 1D 합성곱 필터를 여러 층에 걸쳐 적용

처음 다섯 개의 합성곱 층을 프런트엔드로 간주했으며, 이후 자기 어텐션 백엔드와의 비교를 위해 \(1 \times 7\) 합성곱 층을 추가했다. 다섯 층 이후의 특징 프레임 하나는 약 15.2ms의 오디오를 표현하며, 이는 Spec 프런트엔드의 약 16ms 프레임과 유사하다.

## 2.4 자기 어텐션 백엔드

제안된 Att 백엔드는 트랜스포머의 인코더 구조를 기반으로 한다. 분류 과제이므로 생성에 사용되는 디코더는 제외하고, 여러 개의 자기 어텐션 인코더 층만 사용한다.

각 시간 프레임의 CNN 특징 벡터를 하나의 시퀀스 요소, 즉 NLP의 단어 임베딩과 유사한 것으로 취급한다. 입력 특징 시퀀스 \(X\)로부터 다음을 학습한다.

\[
Q=XW_{\theta}, \quad K=XW_{\phi}, \quad V=XW_g
\]

이후 어텐션은 다음과 같이 계산된다.

\[
Attention(Q,K,V)
=
softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

여기서 \(QK^T\)는 모든 시간 위치 쌍 사이의 관계를 계산한다. 따라서 현재 시간 구간은 인접한 구간뿐 아니라 곡 안의 멀리 떨어진 구간에도 직접 접근할 수 있다.

### 주요 구성

- **다중 헤드 자기 어텐션**
- 트랜스포머 인코더 층
- 전체 시퀀스 문맥을 집약하는 **\([CLS]\) 토큰**
- \([CLS]\) 표현을 기반으로 최종 다중 태그 분류

이 구조의 중요한 장점은 CNN이나 RNN처럼 정보를 순차적으로 압축하거나 반복적으로 전달하지 않고, 모든 시간 위치 사이의 관계를 직접 계산한다는 점이다.

## 2.5 최적화 방법

논문은 ADAM과 SGD의 장점을 결합한 혼합 최적화 방법을 사용했다.

1. 초기 학습:
   - ADAM 사용
   - 학습률 \(1 \times 10^{-4}\)
   - \(\beta_1=0.9\), \(\beta_2=0.999\)
2. 60 epoch 이후:
   - 검증 AUROC가 가장 높았던 가중치로 복원
   - 모멘텀 SGD로 전환
   - 모멘텀 0.9, 네스테로프 모멘텀 사용
3. 80 epoch와 100 epoch:
   - 학습률을 각각 10%씩 감소

ADAM은 빠른 초기 수렴을 제공하지만 후반부 일반화 성능이 저하될 수 있고, SGD는 상대적으로 느리지만 더 나은 일반화에 기여할 수 있다는 점을 이용한 방식이다.

## 2.6 해석 가능성 시각화

논문은 두 가지 유형의 시각화를 제시한다.

### ① 어텐션 히트맵

어텐션 점수를 시간축에 시각화하여 모델이 어느 오디오 구간에 집중했는지를 보여준다. 여러 어텐션 헤드의 점수를 합산해 사용했다.

이를 통해 특정 태그를 예측할 때 모델이 음향 이벤트가 발생하는 부분이나 정보량이 높은 부분에 집중하는 경향을 확인할 수 있다.

### ② 태그별 기여도 히트맵

특정 시간 단계의 어텐션만 선택적으로 활성화한 뒤, 해당 시간 구간이 각 태그 예측에 얼마나 기여하는지 분석한다.

예를 들어 피아노와 플루트가 포함된 두 오디오를 연결해 입력하면,

- “piano” 예측은 피아노 구간에 집중되는지
- “flute” 예측은 플루트 구간에 집중되는지

를 태그별로 비교할 수 있다. 이 방식은 단순 어텐션 히트맵보다 **태그와 입력 구간의 관계**를 더 명확히 보여준다.

# 3. 주요 실험 성과

## 3.1 실험 설정

### 데이터셋

- **MagnaTagATune**
  - 약 26,000개 오디오 클립
  - 상위 50개 태그 사용
  - 비교 가능성을 위해 태그가 하나도 없는 곡을 제거한 약 21,000개 부분집합 사용
- **Million Song Dataset**
  - Last.FM 태그 기반
  - 상위 50개 태그 사용
  - 약 242,000곡 사용
  - 29.1초보다 짧은 오디오 제외

### 입력

- 샘플링 주파수: 16 kHz
- 스펙트로그램:
  - 로그 멜 스펙트로그램
  - 512 샘플 해닝 창
  - 50% 중첩
  - 96개 멜 빈
- 기본 입력 길이: 약 4.1초

### 평가 지표

- **AUROC**
- **AUPR**

태그 분포가 불균형하기 때문에 논문은 AUROC뿐 아니라 정밀도-재현율 기반의 AUPR도 함께 보고했다. 특히 사용자 생성 태그에서는 인기 태그에 편중되는 문제가 있어 AUPR이 중요한 지표가 된다.

## 3.2 정량적 성능

MTAT 검증 세트에서 다음과 같은 결과가 보고되었다.

| 모델 | AUROC | AUPR |
|---|---:|---:|
| Raw \(CNN_L\) | 90.62 | 44.20 |
| Raw Att | **90.66** | **44.21** |
| Spec \(CNN_P\) | **90.89** | **45.03** |
| Spec Att | 90.80 | 44.39 |

핵심적으로, 자기 어텐션 백엔드는 기존 CNN 백엔드와 비교해 **비슷한 수준의 성능을 유지**했다.

- Raw 기반에서는 Raw Att가 Raw \(CNN_L\)보다 소폭 향상
- Spec 기반에서는 Spec Att가 기존 Spec \(CNN_P\)보다 소폭 낮지만 여전히 경쟁력 있는 성능
- 자기 어텐션이 단순히 성능만을 위해 도입된 것이 아니라, 성능 저하를 크게 유발하지 않으면서 해석 가능성을 높였다는 점이 중요

논문에 제시된 전체 테스트 결과에서는 Spec \(CNN_P\)의 MTAT AUROC가 88.75, AUPR이 31.24였고, Spec Att는 각각 88.14와 30.47이었다. Raw Att는 MTAT AUROC 88.07, AUPR 29.90을 기록했다. 제공된 표에서는 MSD 수치가 공란으로 제시되어 있으므로, 본문에 기반해 MSD에서의 구체적인 수치 비교를 단정하기는 어렵다. 다만 저자들은 두 데이터셋 모두에서 Att 백엔드가 경쟁력 있는 성능을 보였다고 결론 내린다.

## 3.3 어텐션 헤드와 층에 대한 절제 연구

어텐션 구조의 크기를 조정한 결과는 다음과 같다.

- 어텐션 층을 2개보다 더 많이 쌓아도 유의미한 성능 향상은 나타나지 않음
- 어텐션 헤드는 8개에서 가장 좋은 결과
- 최종 실험 설정:
  - 어텐션 층: 2개
  - 어텐션 헤드: 8개

이는 약 4.1초 길이 입력에 대해서는 지나치게 깊은 트랜스포머가 필요하지 않음을 의미한다. 모델의 복잡도를 늘리는 것이 반드시 음악 태깅 성능 향상으로 이어지지는 않았다.

## 3.4 최적화에 대한 결과

ADAM만 사용한 경우 초기에는 빠른 성능 향상이 나타났지만, 약 100 epoch 이후 AUROC와 AUPR이 감소했다. 이는 학습 데이터에는 잘 맞지만 일반화 성능이 악화되는 현상으로 해석된다.

반면 제안한 ADAM→SGD 전환 방식은 다음과 같은 특성을 보였다.

- SGD 단독보다 빠른 초기 수렴
- ADAM 단독보다 안정적인 후반 학습
- 검증 성능이 가장 좋았던 가중치를 복원함으로써 전환 시 성능 손실 완화
- 일반화 성능 향상 가능성 확인

따라서 최적화 전략도 모델 구조만큼 중요한 요소로 나타났다.

## 3.5 더 긴 입력 시퀀스에 대한 실험

Spec Att에 약 16.4초에 해당하는 더 긴 입력을 사용한 결과, 약 4.1초 입력보다 성능이 낮아졌지만 비교 가능한 수준을 유지했다.

- 기본 설정: AUROC 90.80, AUPR 44.39
- 긴 입력 설정: AUROC 약 89.62~89.86, AUPR 약 41.61~42.25

이는 자기 어텐션이 더 긴 문맥을 처리할 수 있음을 보여주지만, 단순히 입력 길이를 늘리는 것만으로 성능이 향상되지는 않는다는 점도 드러낸다. 긴 입력에서는 더 많은 어텐션 층이 필요했고, 계산량과 메모리 사용량도 증가했다.

## 3.6 태그별 성능

MTAT의 태그별 AUROC에서는 장르와 악기 태그에서 높은 성능이 나타났다.

예를 들면 다음과 같다.

- metal: 98.79
- choral: 98.68
- choir: 98.65
- rock: 98.52
- opera: 98.34
- flute: 97.91
- piano: 95.69
- guitar: 90.98
- drums: 89.99
- quiet: 90.89

반면 부정 태그는 상대적으로 취약했다.

- no vocal: 71.86
- no vocals: 70.22
- no voice: 67.88

이는 “무언가가 존재한다”는 양성 태그보다 “특정 요소가 존재하지 않는다”는 부정 태그가 음향적으로 더 모호하고, 모델이 침묵이나 부재 자체보다 정보가 많은 음향 이벤트에 주의를 기울이는 경향과 관련된다.

## 3.7 시각화 결과

어텐션 히트맵은 모델이 음악의 관련성이 높은 부분에 집중한다는 점을 보여주었다. 특히 모델은 대체로 오디오 이벤트가 발생하는 구간에 높은 어텐션을 부여했다.

태그별 기여도 히트맵에서는 단순 어텐션 히트맵보다 태그별 차이가 더욱 명확했다.

- 피아노 태그: 피아노가 포함된 구간에 높은 기여도
- 플루트 태그: 플루트가 포함된 구간에 높은 기여도
- 장르·분위기 태그: 특정 구간의 리듬, 음색, 에너지 특성과 연관된 양상
- “slow”와 “fast”, “vocal”과 “no vocals”처럼 대조적인 태그 간 차이도 분석 가능

따라서 자기 어텐션은 분류 성능을 유지하면서 모델이 입력의 어느 위치를 활용했는지 분석할 수 있는 도구를 제공했다.

# 4. 연구의 시사점 및 한계점

## 4.1 연구의 시사점

### ① 음악 태깅에 장기 관계 모델링을 도입

이 논문은 자연어 처리에서 성공한 트랜스포머형 자기 어텐션을 음악 태깅에 적용해, 음악 신호의 시간적 구조를 장거리 관계 관점에서 모델링했다.

CNN의 국소 수용 영역이나 RNN의 순차적 처리에 의존하지 않고 시간 프레임 간 직접적인 관계를 학습한다는 점에서, 음악의 반복, 리듬, 선율 윤곽, 화음 진행과 같은 구조적 정보를 다루는 새로운 방향을 제시했다.

### ② 성능과 해석 가능성의 균형

제안 모델은 기존 CNN 기반 기준 모델보다 월등히 높은 수치를 달성한 것은 아니지만, 성능을 크게 희생하지 않으면서 모델의 내부 작동을 시각적으로 분석할 수 있었다.

즉, 이 연구의 가장 중요한 기여는 최고 성능 기록 자체라기보다는 다음의 결합에 있다.

> **경쟁력 있는 음악 태깅 성능 + 시간 구간 및 태그별 기여도 분석**

이는 음악 추천이나 검색 시스템에서 모델의 판단을 사용자, 음악 전문가, 데이터셋 설계자에게 설명해야 하는 상황에 유용하다.

### ③ 음악을 이벤트 시퀀스로 보는 관점 강화

기존 스펙트로그램 CNN은 시간과 주파수를 동시에 처리하는 이미지 분석 방식에 가까웠다. 이 논문은 CNN을 국소 특징 추출기로 사용하고, 이후 시간 프레임을 시퀀스로 간주해 자기 어텐션을 적용함으로써 음악을 **개별 오디오 이벤트들의 구조화된 시퀀스**로 다룬다.

이는 악기 인식뿐 아니라 다음과 같은 과제에도 확장될 수 있다.

- 박자 및 다운비트 검출
- 리듬 분류
- 음악 전사
- 선율 및 화음 분석
- 음악 구조 분석

### ④ 어텐션 시각화에 대한 비판적 관점

논문은 어텐션이 해석 가능성을 높이는 도구이지만, 어텐션 히트맵만으로 모델의 최종 판단 이유를 완전히 설명할 수는 없다고 명시한다. 즉, “어디를 보았는가”와 “왜 그렇게 분류했는가”는 동일하지 않다.

이를 보완하기 위해 태그별 기여도 히트맵을 제안했다는 점은 해석 가능성 연구에서 중요한 시사점이다. 단일 어텐션 맵을 제시하는 것보다, **태그별로 입력의 기여도를 분리하여 분석**하는 것이 더 유용할 수 있다.

## 4.2 연구의 한계점

### ① 성능 향상이 제한적임

자기 어텐션 백엔드는 경쟁력 있는 성능을 보였지만, 기존 Spec CNN 기준 모델을 일관되게 능가하지는 못했다.

- MTAT 검증:
  - Spec \(CNN_P\): AUROC 90.89, AUPR 45.03
  - Spec Att: AUROC 90.80, AUPR 44.39

따라서 자기 어텐션의 도입이 성능 측면에서 결정적인 우위를 제공한다고 보기는 어렵다. 이 연구의 주된 장점은 성능 향상보다 해석 가능성과 장기 문맥 모델링 가능성에 있다.

### ② 자기 어텐션의 계산 복잡도

자기 어텐션은 모든 시간 위치 쌍의 관계를 계산하므로 시퀀스 길이에 따라 메모리와 계산량이 대략 **이차적으로 증가**한다.

긴 오디오를 입력할수록 다음 문제가 발생한다.

- \(T \times T\) 어텐션 행렬로 인한 메모리 부담
- 더 많은 어텐션 층 또는 효율화 기법 필요
- 입력 길이 증가가 반드시 성능 향상으로 이어지지 않음

논문은 이를 해결하기 위한 방향으로 국소 자기 어텐션, 어텐션 근사, Compact Generalized Non-Local Network와 같은 기법을 제안하지만, 해당 방법들을 실제 음악 태깅 모델에 적용해 검증하지는 않았다.

### ③ 입력 길이가 짧고 음악 전체 구조를 충분히 반영하지 못함

주요 실험은 약 4.1초의 오디오 청크를 사용했다. 이 길이는 모델 간 공정한 비교에는 적절하지만, 음악의 장기 구조를 분석하기에는 제한적이다.

- 곡 전체의 반복 구조
- 절·후렴 간 관계
- 장기적인 화성 진행
- 곡의 전반적 분위기 변화

와 같은 정보는 4.1초 내에 충분히 나타나지 않을 수 있다. 긴 입력 실험에서도 성능이 오히려 낮아졌기 때문에, 향후에는 계층적 구조나 효율적 장기 문맥 모델링이 필요하다.

### ④ 어텐션을 해석 근거로 직접 동일시하기 어려움

어텐션 히트맵은 모델이 주의를 기울인 위치를 보여주지만, 그것이 실제 예측을 결정한 원인이라고 단정할 수는 없다. 논문도 이 점을 인정한다.

특히 “quiet”이나 “no vocal” 같은 태그에서 모델이 조용하거나 보컬이 없는 구간보다 큰 음향 이벤트가 있는 구간에 주의를 기울이는 현상은, 어텐션이 직관적인 의미의 설명과 항상 일치하지 않음을 보여준다.

따라서 향후에는 다음과 같은 방법과의 비교가 필요하다.

- 입력 제거·마스킹 기반 분석
- Integrated Gradients
- 입력 섭동 실험
- SHAP 계열 방법
- 전문가 판단과의 정량적 일치도 평가

### ⑤ 부정 태그 및 데이터셋 편향

“no voice”, “no vocal”, “no vocals”의 성능이 낮은 것은 모델 구조뿐 아니라 데이터셋의 태그 품질과 분포에도 영향을 받을 수 있다. 사용자 생성 태그는 일관성이 낮고, 태그의 부재가 실제로 오디오에 해당 요소가 없다는 뜻인지 불분명할 수 있다.

또한 태그 분포의 인기도 편향으로 인해 모델이 음악적 본질보다 데이터셋의 통계적 상관관계를 학습할 가능성도 존재한다. 따라서 보다 정밀한 주석, 태그 의미의 표준화, 부정 태그 전용 평가가 필요하다.

## 종합 평가

이 연구는 자기 어텐션을 음악 태깅에 적용해 **국소 음향 특징과 장기 음악 구조를 결합**하고, 모델의 판단 과정을 시간 구간과 태그별로 시각화하려는 초기의 중요한 시도이다. 정량적으로는 기존 CNN을 압도하지 않았지만, 성능을 유지하면서 모델의 주의 위치와 태그별 기여도를 분석할 수 있다는 점에서 의미가 크다.

다만 어텐션 기반 설명의 신뢰성, 긴 시퀀스 처리 비용, 짧은 입력 길이, 부정 태그 취약성 등의 문제가 남아 있다. 따라서 후속 연구에서는 효율적인 장기 어텐션, 계층적 음악 표현, 인과적 설명 기법, 전문가 평가 및 더 정교한 데이터셋을 결합하는 것이 핵심 과제가 된다.
